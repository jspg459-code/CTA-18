# StreamTV

StreamTV est un lecteur IPTV web gratuit en V1. Les utilisateurs peuvent connecter leurs propres playlists autorisées M3U/M3U8 ou Xtream Codes, puis parcourir TV en direct, films et séries.

## Stack
- Next.js
- Supabase
- Vercel
- GitHub

## V1
- Interface responsive premium
- Gestion de plusieurs playlists
- Import M3U/M3U8
- Préparation Xtream Codes
- TV / Films / Séries
- Favoris et historique
- Lecteur HTML5

StreamTV ne fournit ni ne redistribue de contenus IPTV. L'utilisateur est responsable des droits relatifs aux sources qu'il ajoute.
